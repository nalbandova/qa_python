# qa_python
Тесты покрывают функциональность класса `BooksCollector`.

## Список тестов

### 1. `test_add_new_book_add_one_book`
Проверяет, что при добавлении новой книги она появляется в словаре `books_genre`,
причём жанр у неё по умолчанию пустой.

### 2. `test_add_new_book_too_long_name_not_added`
**Параметризованный тест.** Проверяет, что книга с названием длиннее 40 символов
не добавляется в словарь. Параметры: название из 41 и из 100 символов.

### 3. `test_add_new_book_duplicate_not_added_twice`
Проверяет, что одну и ту же книгу нельзя добавить в словарь повторно —
количество записей в словаре не увеличивается.

### 4. `test_set_book_genre`
**Параметризованный тест.** Проверяет установку жанра книге:
- если жанр входит в список допустимых (`'Фантастика'`, `'Ужасы'`) — он устанавливается;
- если жанр не входит в список допустимых — жанр книги остаётся пустым.

Одновременно проверяется и метод `get_book_genre`, так как через него мы
считываем результат установки жанра.

### 5. `test_get_books_with_specific_genre`
Проверяет, что метод возвращает только те книги, у которых указан искомый жанр,
и не включает книги других жанров.

### 6. `test_get_books_genre_returns_full_dict`
Проверяет, что метод возвращает весь словарь `books_genre` в правильном виде —
с названиями книг и их жанрами.

### 7. `test_get_books_for_children_excludes_age_rated_genres`
Проверяет ключевое правило приложения: книги с жанром, имеющим возрастной
рейтинг (например, `'Ужасы'`), не попадают в список книг для детей, а книги
без возрастного рейтинга (например, `'Мультфильмы'`) — попадают.

### 8. `test_add_book_in_favorites`
Проверяет добавление книги в избранное:
- книгу можно добавить, если она есть в словаре `books_genre`;
- повторное добавление той же книги не создаёт дубликат;
- книгу, которой нет в словаре, добавить в избранное нельзя.

### 9. `test_delete_book_from_favorites`
Проверяет, что книга корректно удаляется из списка избранного.

### 10. `test_get_list_of_favorites_books`
Проверяет, что метод возвращает список избранных книг в том порядке,
в котором они были добавлены.
